This $100 million project, led by entrepreneur Bryan Johnson, aims to develop a neural device designed to boost human intelligence, with an initial focus on enhancing memory through the hippocampus. By studying epilepsy patients who already have electrical brain implants, researchers are recording normal neural activity to understand how memory functions so they can eventually mimic it using personalized algorithms. Building on encouraging initial tests on animals, the primary medical objective is to create a neural prosthesis that restores memory in patients suffering from cognitive disorders or brain trauma. Beyond medical treatment, the project's ultimate ambition is to create a small, easy-to-implant chip accessible to healthy individuals, thereby enhancing human memory and eventually expanding to stimulate other regions of the brain.
